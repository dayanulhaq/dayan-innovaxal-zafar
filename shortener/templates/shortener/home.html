API Documentation

GET /shorten/<shortcode>/
Retrieves the original URL and statistics for a given shortcode.
GET http://127.0.0.1:8000/shorten/abc123/
PUT /shorten/<shortcode>/update/
Updates the original URL for a given shortcode.
PUT /shorten/abc123/update/
Content-Type: application/json

{
  "url": "https://www.updated.com"
}
DELETE /shorten/<shortcode>/delete/
Deletes the entry for a given shortcode.
DELETE /shorten/abc123/delete/
GET /shorten/<shortcode>/stats/
Returns statistics like number of visits for a given shortcode.
GET /shorten/abc123/stats/
GET /<shortcode>/
Redirects to the original URL when someone visits the short URL in their browser.
